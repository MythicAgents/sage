# Development and test dependencies.
#
# Kept separate from requirements.txt because the Dockerfile installs only the runtime manifest
# (`COPY requirements.txt .` → `pip install -r requirements.txt`); nothing here belongs in the
# shipped image. Installing this file also installs the runtime deps, so one command is enough:
#
#   .venv/bin/python -m pip install -r Payload_Type/sage/requirements-dev.txt
#
# Deliberately absent: pytest-asyncio. The suite does not configure it and writes async tests
# against explicit event loops instead — several test modules state this convention directly.
# Adding it would silently change collection semantics for those tests.

-r requirements.txt

pytest==9.1.1

# Operator-skill dependency, not a runtime one. `skills/sage-goad-reset/scripts/sync_range_time.py`
# imports `winrm` to set Windows guest clocks over WinRM after a range rollback — a step AGENTS.md
# calls mandatory after *every* rollback. It went undeclared until 2026-08-01, so a clean checkout
# hit `ModuleNotFoundError: No module named 'winrm'` on a documented-required command.
# `tests/repo_hygiene/test_skill_dependencies.py` now fails on any undeclared skill import.
pywinrm==0.5.0

# `skills/sage-goad-reset/scripts/pkinit_padata_probe.py` imports pyasn1 directly to decode KDC
# PA-DATA. It arrives transitively through ldap3 today, which is declared — but a direct import
# resting on someone else's transitive breaks silently the day that edge disappears.
pyasn1==0.6.4
